# Security policy

Report vulnerabilities privately to **support@armoreum.io** with the subject `Security report: Armoreum Contracts`.

Identify the affected commit and contract or script, describe prerequisites and impact, and include a minimal local reproduction using synthetic data. Never send live signing keys, seed phrases, recovery capsules, passwords, API tokens, or customer records.

Do not test an exploit against live deployments or other people's funds. Avoid public disclosure until the issue can be assessed. No response deadline or bounty is promised by this policy.

This is a source preview, not an audited or production-supported release. A source-level fix does not establish that any deployed proxy or contract has been upgraded.

Treat any disclosed credential as compromised and revoke or rotate it. Removing a credential from a current file does not remove it from prior copies or history.
